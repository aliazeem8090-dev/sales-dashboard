# Environment Variables

```
JWT_SECRET="your-jwt-secret"
OPENAI_API_KEY="your-openai-api-key"
```

```
NEXT_PUBLIC_API_URL="http://localhost:3001"
NEXTAUTH_SECRET="your-nextauth-secret"
NEXTAUTH_URL="http://localhost:3000"
```
