# AI Scoring Rubric

## Proposal Evaluation Parameters

### 1. Hook Strength (20 points)
- **Excellent (18-20)**: Compelling, specific opening that immediately grabs attention
- **Good (14-17)**: Clear value proposition in first sentence
- **Average (10-13)**: Generic but relevant opening
- **Poor (0-9)**: No clear hook or irrelevant opening

### 2. Personalization (15 points)
- **Excellent (13-15)**: Specific client details, company research, tailored approach
- **Good (10-12)**: References job requirements specifically
- **Average (7-9)**: Generic personalization attempts
- **Poor (0-6)**: No personalization or copy-paste approach

### 3. Pain Point Clarity (15 points)
- **Excellent (13-15)**: Clearly identifies and addresses specific client challenges
- **Good (10-12)**: Addresses general pain points from job description
- **Average (7-9)**: Vague understanding of client needs
- **Poor (0-6)**: No mention of client problems or needs

### 4. Technical Credibility (15 points)
- **Excellent (13-15)**: Demonstrates deep expertise with specific examples
- **Good (10-12)**: Shows relevant experience and skills
- **Average (7-9)**: Lists skills without context
- **Poor (0-6)**: Generic or irrelevant technical claims

### 5. Portfolio Relevance (10 points)
- **Excellent (9-10)**: Specific, relevant project examples included
- **Good (7-8)**: Relevant portfolio mentioned
- **Average (5-6)**: Generic portfolio reference
- **Poor (0-4)**: No portfolio mention or irrelevant examples

### 6. CTA Strength (10 points)
- **Excellent (9-10)**: Clear, compelling next steps with timeline
- **Good (7-8)**: Specific call to action
- **Average (5-6)**: Vague next steps
- **Poor (0-4)**: No clear call to action

### 7. Tone & Brevity (10 points)
- **Excellent (9-10)**: Professional, human tone; concise and focused
- **Good (7-8)**: Appropriate tone, reasonable length
- **Average (5-6)**: Slightly verbose or formal
- **Poor (0-4)**: Too long, robotic, or unprofessional

### 8. Profile Alignment (5 points)
- **Excellent (5)**: Perfect match with assigned expertise
- **Good (4)**: Good fit within profile capabilities
- **Average (3)**: Acceptable fit
- **Poor (0-2)**: Outside profile expertise or poor fit

## Profile-Specific Adjustments

### MERN Stack Profile
- Higher weight on JavaScript/React/Node.js examples
- Emphasis on full-stack development capabilities
- Frontend/backend integration examples

### Laravel Profile
- PHP/Laravel-specific project examples
- Backend API development focus
- Database design and optimization

### AI/ML Python Profile
- Machine learning project examples
- Data science portfolio emphasis
- Technical algorithm explanations

### WordPress Profile
- CMS development examples
- Plugin/theme customization
- E-commerce integration

## Scoring Weights
- Hook: 20%
- Personalization: 15%
- Pain Points: 15%
- Technical Credibility: 15%
- Portfolio: 10%
- CTA: 10%
- Tone/Brevity: 10%
- Profile Alignment: 5%

## Minimum Standards
- Overall Score: 70/100
- No category below 6/10
- Profile Alignment: Must be 3/5 or higher
